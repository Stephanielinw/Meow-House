Conclusion: meaningful applied changes can be invisible in normal Hall play. The archive is accurate but buried: the profile opens Daily by default, then the player selects Relationship, selects a resident, and inspects history. No small toast, scene footer, history indicator on the Hall card, or status badge announces a substantive change. A directional A→B-only change can appear absent on A's summary card if the USER is viewing B's summary: the list favors the owner direction and only hints that the other side changed; pair detail shows both directions. No confirmed stale UI or reload-only refresh problem was found.
