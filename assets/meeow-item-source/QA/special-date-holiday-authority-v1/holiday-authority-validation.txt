State and authority
- Date authority: device/browser local year, month and day.
- Holiday boundary: local 00:00; existing 03:00 game operational day remains separate.
- Structured state: {version, dateKey, holidays[], primaryHolidayId, lunar:{available,errorCode}}.
- Rules: 21 total (10 Gregorian; 10 fixed lunar plus computed 除夕).
- Current state is derived in memory and is not persisted or migrated.

- Missing/failed conversion reports lunar-library-unavailable or lunar-conversion-failed;
  Gregorian holidays remain available and the Hall does not crash.

Hall and interaction wiring
- Holiday banner is driven by holidayState, separate from alfredMessage.
- Theme CSS uses --ui-text, --accent, --accent-dim, --ui-surface-strong,
  --ui-border-strong and --ui-surface-soft.
- Timer targets the next local midnight; visibility and focus reschedule it.
- Structured interaction context is empty on ordinary days and only contains
  dateKey plus ordered id/name/greeting entries on holidays.
- Hall direct and Phone sidecar use one captured dispatch-time context; standalone
  Phone Direct Reply obtains the current shared state at dispatch.
- AI output cannot mutate or select the calendar authority. No AI request added.
- Broad character memory date context omits holiday duplication; selected live
  interaction prompts receive the explicit structured context block.
- Historical archive evaluation uses its explicit recorded date, never today's holiday.
