HOUSE BASE SPRITE LIBRARY — REFERENCE SHEET PLAN V1
Audit date: 2026-09-24

PURPOSE

Plan five practical human/reference drawing sheets for 40 generic 64×64 first-party
sprites. This file does not create art or register IDs. Each sprite should be a broad
resolver archetype, not a named Meeow House product.

SHARED ART BRIEF FOR ALL FUTURE SHEETS

- True native 64×64 pixel art with transparent background.
- Crisp integer pixel grid; no antialiasing or soft resampling.
- Cozy, rounded, readable Meeow House item-icon language.
- 2 px minimum transparent safety margin; 3–5 px preferred where practical.
- Strong silhouette at the shared small/medium renderer sizes.
- Avoid product-specific garnish, labels, or compositions that imply housefood:*.
- One concept per cell, with exact proposed ID and visualHint printed beside it.
- Reference sheets are art direction; final sprites require user review before registry.
