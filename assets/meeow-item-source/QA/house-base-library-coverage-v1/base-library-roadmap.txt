HOUSE BASE SPRITE LIBRARY — ROADMAP V1
Audit date: 2026-09-24

TARGET

40 proposed first-party generic sprites:
- 24 Food/Drink
- 16 non-food
- 28 P0 (draw first)
- 12 P1 (next)

Future namespaces:
- basefood:<semantic-name>
- baseitem:<semantic-name>

No ID below is registered. These are planning names only.

SELECTION PRINCIPLES

1. Use only current closed visualHint values.
2. Prefer broad reusable silhouettes over named recipes or canon products.
3. Keep housefood:* reserved for exact built-in products.
4. Give one sprite a clear semantic role under the current resolver.
5. Do not draw multiple subtypes with identical complete hint tuples unless one is
   intentionally a fallback; the current resolver cannot select them by item name.
6. P0 emphasizes frequent actual gaps plus the product-required Food foundation.
7. P1 fills lower-frequency roles that add meaningful range without overfitting.

P2 — LATER / LEGACY ICON IS ACCEPTABLE

- Nature/material: stick, seed, mushroom, gem, bone.
- Paper/display: book, scroll, photo.
- Containers/household: cup, jar, box, bag, basket.
- Jewelry/textile/craft: ring, necklace, cloth, ribbon, rope.
- Specific food subtypes: soup, stew, noodles, salad, dumplings, pizza/flatbread,
  croissant, cookie, chocolate, pudding, jelly, yogurt, ice cream, milk, tea, coffee,
  juice, berries, citrus, cheese.

The food subtype list is deferred because those names are not closed object values and
many collapse to identical hint tuples. Drawing them now would not make them reliably
selectable through the current resolver.

ARCHITECTURE PREREQUISITE BEFORE REGISTRATION

The art can be drawn and reviewed independently, but production registration should not
occur until generic resolution stops considering canonical housefood:* entries. A safe
future change should preserve all existing builtin-sprite mappings while making the
basefood/baseitem pool the explicit generic candidate pool.

When a shared object has incompatible roles, register enough tagged candidates to avoid
object-only hijacking. Example: bottle/beverage/food versus bottle/container/fantasy.
Do not modify the closed taxonomy merely to land V1 art.
