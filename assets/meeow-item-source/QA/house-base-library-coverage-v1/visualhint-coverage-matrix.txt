RESOLUTION CONSEQUENCES

- Resolver weight: object=12, material=3, form=3, context=1.
- Acceptance threshold: 12.
- Exact object match alone makes a candidate eligible.
- Secondary values rank candidates sharing an object but cannot prevent a lone wrong-role
  candidate from matching every hint with that object.
- Sprite aliases are not scored.
- Name and description are not resolver inputs.
- Multiple sprites with the same complete hint tuple are not independently addressable;
  score ties resolve by quality tier and lexical sprite ID.

PLANNING RULE DERIVED FROM THE MATRIX

Base Library V1 should prefer one broad sprite per distinct, useful object/form role.
Where one object must support incompatible roles (for example bottle as beverage versus
potion/container), the library needs both candidates with accurate secondary tags.
Highly specific food concepts that share the same tuple should not be multiplied until
a future approved discriminator exists.
